# LAPORAN PRAKTIKUM 4
## CSS Layout

### A. Tujuan Praktikum

1. Memahami struktur dasar layout pada halaman web.
2. Memahami penggunaan elemen box pada HTML.
3. Memahami penggunaan CSS Float dan Clear.
4. Memahami penggunaan elemen HTML5 dalam pembuatan layout.
5. Membuat layout website sederhana menggunakan HTML dan CSS.

### B. Alat dan Bahan

1. Laptop atau komputer.
2. Visual Studio Code.
3. Web browser.
4. HTML dan CSS.
